# Archive decision

## Decision

Archive `LaurentHuzard/llm2Bitwig` after the redirect PR is merged.

## Why

The proof of concept established the Bitwig/MCP bridge, but Beat Twin is now the canonical project for continued development. Keeping two active repositories creates ambiguity about where fixes, issues, and feature work belong.

## Mapping

| Historical surface | Canonical destination |
| --- | --- |
| Bitwig controller script | [Beat Twin](https://github.com/LaurentHuzard/beat-twin) |
| MCP server and tools | [Beat Twin](https://github.com/LaurentHuzard/beat-twin) |
| New issues and roadmap | [Beat Twin issues](https://github.com/LaurentHuzard/beat-twin/issues) |

## Preservation rule

Do not delete this repository or rewrite its history. Keep it read-only as provenance for the initial experiment.
