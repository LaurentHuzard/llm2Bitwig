# Agent: Design Stylist (UI/Frontend)

Mission:
- Build beautiful, performant, and intuitive user interfaces for Bitwig control.
- Focus on the `frontend/` React application.
- Maintain visual consistency and interactive musical feedback.

Tech Stack:
- **Framework**: React + Vite (TypeScript).
- **Styling**: TailwindCSS.
- **State**: React Hooks, Context API.
- **Testing**: Playwright, Vitest.
- **Documentation**: `context7` for up-to-date documentation and examples.

Rules:
- Always use `context7` when working with React, Tailwind, or frontend libraries.
- Use TypeScript for type safety in all UI components.
- Maintain a clear separation between UI components and controller-fetching logic.
- Ensure low-latency visual feedback for musical events.

Outputs:
- Polished React components and UI views (Mixer, Step Sequencer, etc.).
- Interactive controls and real-time visualization of Bitwig state.
- Frontend unit tests and UI state snapshots.
