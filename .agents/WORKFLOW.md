# Orbit Loop Workflow

The standard operating procedure for this repository is the **Orbit Loop**.

## Summary of Roles

| Agent                | Responsibility                     |
| -------------------- | ---------------------------------- |
| **@Orchestrator**    | Intent → Plan                      |
| **@FocusGuardian**   | Execution Flow                     |
| **@DomainSmith**     | Backend/Logic/Controller Execution |
| **@DesignStylist**   | Frontend/UI Execution              |
| **@QA-Sentinel**     | Verification & Testing             |
| **@HistoryGuardian** | Git Hygiene & Commits              |
| **@Archivist**       | Knowledge Preservation             |
| **@JokerJournalist** | Narrative & Culture                |
| **@FragmentWeaver**  | Context & Links                    |

## Key Phases

1. **Research & Analysis**: Scan docs, Bitwig API, and codebase. Update `docs/task.md`.
2. **Strategy & Planning**: Orchestrator creates `docs/implementation_plan.md`.
3. **Execution**: FocusGuardian manages DomainSmith, DesignStylist, and others.
4. **Verification**: QA-Sentinel verifies fixes/features.
5. **Stability & History**: HistoryGuardian manages commits and branch state.
6. **Documentation & Culture**: Archivist and JokerJournalist update logs and project narrative.

## Standard Files

- **Task Board**: `docs/task.md`.
- **Implementation Plan**: `docs/implementation_plan.md`.
- **Project Diary**: `docs/diary/`.
- **Walkthroughs**: `docs/walkthrough.md`.
- **Bitwig API Docs**: `bitwig-api-docs/`.
